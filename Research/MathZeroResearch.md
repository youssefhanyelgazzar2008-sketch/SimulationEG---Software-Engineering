## 1. Abstraction — 3 Real-World Examples

- **Calculator**

  When using a calculator, the user simply presses numbers and operators such as +, -, *, and / to get the result without knowing how the internal circuits or computational processes perform these operations.

- **Using a Computer**

  A user can interact with a computer through a simple graphical interface, such as clicking icons or opening applications, without understanding the complex operations performed by the CPU, RAM, and other hardware components.

- **ATM**

  When using an ATM, the user inserts a card, enters a PIN, and withdraws money without knowing the internal processes of verifying the card, checking the PIN and account balance, and processing the transaction.

## 2. Pattern Recognition — 3 Real-World Examples

- **X-ray Analysis**

  AI-powered X-ray systems recognize patterns in medical images by comparing them with previously learned images of normal and abnormal bones. This helps doctors detect fractures more accurately and reduces the possibility of missing an injury.

- **Face ID**

  Face ID scans a person's face and recognizes patterns in facial features, such as the shape and distance between different parts of the face. It compares these patterns with previously stored facial data to determine whether the person is authorized to unlock the phone.

- **Spam Email Filter**

  Email spam filters recognize patterns in emails, such as repeated messages, suspicious links, certain keywords, and unusual sending behavior. By identifying these patterns, the system can automatically classify suspicious emails as spam and make it easier for users to find legitimate messages.

## 3. One Problem, Many Solutions

Programming depends on logic and algorithms, and different programmers may think differently, so the same problem can have multiple correct solutions. I think we should choose a solution based on the requirements of the task or software. For example, speed and memory usage are important when dealing with large amounts of data. However, readability and maintainability are also important because other programmers may need to understand or modify the code later. The shortest solution is not always the best one. In some cases, a simple and readable solution is better than a faster but more complicated one. Therefore, we should balance performance, memory usage, readability, and maintainability depending on the situation.

## 4. What is a Markdown (.md) file?

Markdown is a lightweight markup language used to format plain text using simple symbols, such as # for headings and * for italic text. It is commonly used for technical documentation because it is easy to write, read, edit, and share. It allows developers to organize information, add code blocks, create lists, and include links without using complicated formatting tools. Markdown files are commonly used in README files, GitHub repositories, and documentation.
